## Hi there 👋


1.git init
(Initializes a brand new, empty local Git repository in your current project folder.)

2.git add .
(Stages all new, modified, or deleted files in the directory, preparing them for a snapshot.)

3.git commit -m "Your commit message"
(Takes a local snapshot of your staged changes and labels them with a descriptive message.)

4.git remote add origin <URL>
Links your local repository to a specific remote server URL (e.g., https://github.com).

5.git push -u origin main
(Uploads your local commits to the main branch on the remote server and sets it as the default tracking branch.)

Update repo
1.git status
(Optional but highly recommended) This shows you exactly which files you have edited or added.

2.git add .
This stages all of your edited files, preparing them to be saved in a snapshot.If you only want to stage a single file, use git add filename.ext instead.

3.git commit -m "Describe your edits here"
This saves your staged changes locally with a message explaining what you modified or fixed.

4.git push
This uploads your new commit and updates your remote repository. Because you already set up the upstream tracking branch during your first upload, you do not need to type origin main anymore.
